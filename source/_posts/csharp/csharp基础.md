## 1. 语法

### 1.1 复杂数据类型

- **枚举**
  - **基本概念**
    - 被命名整型常量集合
    - **在namespace声明枚举（常用）或者写class和struct里**
      - 不能在函数语句声明
    - **声明枚举**
      - 自定义一个枚举类型
      - 语法

        示例代码如下：

        ```csharp
        enum E_自定义枚举名
        {
        	自定义枚举名字，
        	自定义枚举名字1，
        }
        ```

        - E\_是命名规范
        - 枚举的值会自己累加1
  - **枚举的使用**
    - 声明枚举变量在函数中用
    - **声明枚举变量**
      - E\_player playtype=E\_player.main;
      - 自定义枚举类型 变量名 =默认值；（自定义枚举类型.枚举项）
    - 枚举和变量天生一对
  - **枚举的类型转换**
    - int i =(int)枚举变量
    - 枚举变量=（枚举名）常数变量
    - 枚举变量=（枚举名）Enum.parse(typeof(枚举名)，“枚举子名字”)
- **数组**
  - **一维数组**
    - 数组声明
      ```csharp
      数组类型[ ] 数组名；	只是声明，没赋值
      数组类型[ ] 数组名=new 数组类型[数组长度];里面值默认为0
      数组类型[ ] 数组名=new 数组类型[数组长度]{内容1，内容2，内容3};
      数组类型[ ] 数组名=new 数组类型[ ]{内容1，内容2，内容3，……};   后面内容决定房间数
      数组类型[ ] 数组名={内容1，内容2，内容3，……}; 后面内容决定房间数
      ```

    - **数组使用**
      - 数组的长度  数组名.Length
      - **获取数组中元素 数组名\[0\]**
        - 元素从0开始
        - 一定不能越界
      - **遍历数组**
        - 通过循环获取所有元素
      - **增加删除数组元素**
        - 初始化数组不能增添 删除元素
        - 需要新建数组搬家，然后让旧数组=新数组
      - 查找数组元素只能遍历
  - **二维数组**
    - 数组声明
      ```csharp
      变量类型[ , ] 变量名；	未初始化
      变量类型[ , ] 变量名=new 变量类型[行，列]；
      变量类型[ , ] 变量名=new 变量类型[行，列]{ {0行内容}，{1行内容}……}；
      ```

    - **数组使用**
      - **二维数组长度**
        - **获取行和列分别是什么**
          - 数组名.GetLength( 0 )	获取行<br>数组名.GetLength( 1 )	获取列
      - **获取元素**
        - 数组名\[行，列\]
  - **交错数组**
    - 行数确定，每行列数不同
    ```csharp
    变量类型[ ][ ] 交错数组名 =new 变量类型[行数][ ]；
    变量类型[ ][ ] 交错数组名 =new 变量类型[行数][ ]{new int[ ]{1,2,3},new int[ ]{1,2,3}}；
    ```

    - 第0行列获取	数组名\[0\].Length<br>第n行列获取	数组名\[n\].Length
- 结构体

### 1.2 值类型和引用类型

主要包括：

- 引用类型：string（特殊，不遵循规律），数组，类<br>值类型：其他，结构体
- 值类型：在相互赋值时把内容给对方，它变我不变<br>引用类型：在相互赋值时，两者指向同一值，两者同时变
- 值类型存储在栈中，系统分配，自动回收小而快<br>引用类型存储在堆空间，手动申请和释放，大而慢
- new就相当于新开个堆的房间
- **string的特点**
  - C#对string有特殊处理让它和值类型一样能随时改变，但会产生内存垃圾，需特殊处理
  - 使用断点，在监视窗口看指针变化	&amp;变量名

### 1.3 函数

- **函数基础**
  - **写哪里**
    - class语句块，或struct语句块（结构体）中
  - 语法

    示例代码如下：

    ```csharp
    static 返回类型 函数名（参数类型 参数名1，参数类型 参数名2，……）
    {
    函数代码逻辑；
    return 返回值；（可选，如果有返回类型才写）
    }
    ```

    - void代表空，无返回值
    - 返回类型可以选任意变量类型
    - 函数名用帕斯卡命名法，全部单词首字母都大写
    - 参数不是必须的，可以是任意类型
  - **调用函数**
    - 函数名（）；
  - **多返回值函数**
    - 只能返回一个值，若有多个值要用数组
    ```csharp
    return new int {a，b}；
    或函数内建一个数组
    ```

  - return可以当break用
- **ref和out**
  - 当传入的值参数想改变外部值，或数组想重新声明时使用
  - **ref**
    - **只要在括号内加ref**
      - static void 函数名（ref int a）
      - 应用：函数名（ref 变量）
  - **out**
    - 和ref用法一样
  - **区别**
    - ref必须初始化，out不用
    - out必须在函数内部赋值，ref不用
- **变长参数和参数默认值**
  - **变长参数**
    - 需要引用的参数数量不定
    - 括号内写（params int\[ \] arr）意味传入n个整数，组成数组形式
    - **注意**
      - params后面必须是一维数组
      - 数组可以是任意类型
      - 函数参数可以有别的参数和params的参数<br>但params只能有一个且放在最后
  - **参数默认值（可选参数）**
    - 当使用函数是可以不传参数，使用默认值作为参数
    - 函数括号内（string str=“无”）<br>引用参数时可以括号为空，默认str为无，有填入的话就是填入的值
    - 支持每个参数都有默认值，如果要混用，有默认值参数写普通参数后面
- **函数重载**
  - 同一语句块中，函数名相同，参数数量或类型，顺序不同
  - 调用时会自动判断
  - **语法**
    - 相同名字，参数数量，类型，顺序不同即可<br>不用额外语法
    - 加入ref 和out也算重载，但是ref和out意思相同，两者之间不算重载
    - 可选参数不算重载，变长参数算
- **递归函数**
  - 往函数内调用自己
  - 必须有结束的条件，用于条件判断的条件必须能够达到停止的目的

### 1.4 结构体

主要包括：

- 数据和函数的集合
- 和枚举一样，写在namespace中
- 语法

  示例代码如下：

  ```csharp
  struct 自定义结构体名
  {
  第一部分（变量）
  第二部分（构造函数）
  第三部分（函数）
  }
  ```

  - 帕斯卡命名法
  - 结构体变量可以是任意类型，包括结构体，但不能是自己
  - 结构体中构建函数不用写static
- **访问修饰符**
  - 公用public，能在其他地方使用
  - 私有private，只能在结构体内使用，不写默认为私有
  - 给变量和函数定义修饰符
- **使用**
  - 结构体名.函数或变量
- **结构体构造函数**
  - **特点**
    - 没有返回值
    - 必须和结构体同名
    - 必须有参数
    - 必须对其中变量初始化
    - 若构造函数变量和结构体变量重名，使用this.变量名表示自己的变量
    - 构造函数可以重载
  - 构造函数建立后，可以	结构体 结构体名=new 构造函数名（参数，参数）
  - 用来快速初始化

### 1.5 排序

- **冒泡排序**
  - n个数，两两相邻不停比较，比较n轮
  - **做法**
    - 建立循环，比较n和n+1处值
    - 交换位置
    - 比较n轮
    - 优化	每循环一次，去掉最大值<br>比较一次后检查一次
- **选择排序**
  - 寻找中间商，依次比较找极值，比较n轮
  - **做法**
    - 创建中间值
    - 依次比较，找最值
    - 放入目标位置（判断目标位置与中间值是否不一样，比一样就放）
    - 重复n轮
