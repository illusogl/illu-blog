## 6. 类型转换

再整理类型转换。

### 6.1 隐式转换

- **相同类型的转换**
  - 大范围装小范围

    示例代码如下：

    ```csharp
    int i;long l;		 l=i成立但i=l错误
    ```

- **不同类型的转换**
  - 无符号不能装有符号
  - 有符号能装无符号，但要下放等级	例int只能装sbyte，不能装uint
  - 浮点数能装任何整数，无关大小
  - string和bool没有办法相互转换其他类型
  - **char不能装其他类型，但char能转换成数值类型**
    - 转换的对应数字是ASCLL码
- decimal不能用隐式转换装float和double

### 6.2 显示转换

主要包括：

- **括号强转**
  - 变量类型 变量名=（变量类型）变量；<br>int i =1;	short s = 1;	s = (short) i  ;
    - 括号强转可能会有范围问题造成的异常
    - 浮点之间转换只会影响精度
    - 浮点强转整形会丢掉小数
    - bool和string不支持强转
- **parse法**
  - int i = int.parse("123");<br>变量类型.parse("字符串")；
    - 字符串必须能转成转换类型
- **Convert法**
  - Convert.To目标类型（变量或常量）；

    示例代码如下：

    ```csharp
    例 int a =Convert.ToInt32(1.3455f);
    ```

    - float f =Convert,ToSingele("3.234");
    - 任意类型均可转换，但要符合范围
- 其他类型转string
  ```csharp
  变量.ToString( );
  int a = 6;
  string str = a.ToString();
  ```

## 8. 运算符

接下来整理运算符。

### 8.1 算数运算符

主要包括：

- **赋值符号 =**
  - 把右侧的值给左侧
- **算数运算符**
  - + - \* / %加减乘除取余
  - /运算会丢失小数位，需要用浮点形式 例 float f1 =1f / 2
- **优先级**
  - 乘除取余 &gt; 加减
  - 括号可以改变优先级 多组括号先算最里面的括号
- **复合运算符**
  - **+=	-=	\*=	/=	%=<br>自己等于自己的运算**
    - i%=3;是	i = i % 3;
- **自增减**
  - a++先用再加	++a先加再用

### 8.2 字符串拼接

主要包括：

- string不能进行算术运算，使用+是字符拼接
- 字符串拼接只能用+  +=，不能用++，-
- **其他方法**
  - string.Format("带拼接内容"，内容1，内容2， ......);
  - 拼接内容为{数字}
  - 例 string str = string.Format("我是{0},今年{1}，我想要{2}"，"illu"，20，"做游戏")；
  - 多填不报错，少填报错
- 控制台打印

  示例代码如下：

  ```csharp
  Console.WhiteLine("A{0}B{1}",awe,aew);
  ```

### 8.3 条件运算符

主要包括：

- **符号**
  - &gt;	==	&lt;	!=	&gt;=	&lt;=
  - 比较的结果是bool值，正确为true,错误为false
  - 纯比较无意义
  - 条件运算符 优先级低于 算术运算符
- **不能范围比较**
  - 若要判断1&lt;a&lt;6,不嫩写bool bo = 1 &lt; a &lt; 6;
- **不同类型比较**
  - 不同数值类型之间可以随意进行比较
  - **char string bool 只能与同类型比较，只有==和！=**
    - char可以和数值比较

### 8.4 逻辑运算符

主要包括：

- 逻辑运算符 优先级低于 条件运算符 低于 算术运算符（逻辑非除外）
- 与&amp;&amp; ，and的意思<br>有假则假，同真则真
- 或|| , or的意思<br>有真则真，同假则假
- 非 ! ,对bool值取反<br>真变假，假变真
- 逻辑非！优先级最高，&amp;&amp;优先级高于||
- **逻辑运算符短路规则**
  - 只要逻辑与和或左边满足了条件，右边内容不会计算

    示例代码如下：

    ```csharp
    int i= 1;
    bool result= i>0 ||  i++>1
     i的值为1
    或有真为真，左侧值为真右边就不计算
    与同理
    ```

### 8.5 位运算符

主要包括：

- **位与 &amp;<br>连接两个数 转成2进制 进行位运算 有0则0**
  - 1 &amp; 5 = 1<br>001 &amp; 101 =001（二进制表示）
- 位或 |<br>连接两个数 转成2进制 进行位运算 有1则1
- 异或 ^<br>相同为0，不同为1
- 位取反~<br>写在数值前面 将数值变2进制 0变1， 1变0
- 左移&lt;&lt;和右移&gt;&gt;<br>让一个二进制进行移动<br>左移几位右侧加几个0<br>右移几位右侧去掉几个数

### 8.6 三目运算符

- **语法**
  - 三个空位，两个符号

  示例代码如下：

  ```csharp
  空位？空位：空位；
  bool类型？bool为真返回的值：bool为假返回的类型；
  例string str =(1>0) ?  "真" : "假" ;
  ```

### 9.3 switch语句

```csharp

{

case 常量:
```

## 10. 循环语句

接着整理循环语句。

### 10.1 while

- 语法

  示例代码如下：

  ```csharp
  while（bool类型的值）
  {//满足条件执行的代码
  }
  ```

  - 如果执行完还满足条件，则继续执行代码
  - 死循环会让程序卡死
- 若在循环内声明变量，每次循环内的变量都没有联系
- **循环关键字**
  - break；<br>跳出循环
  - continue；<br>回到循环开始，继续执行
  - continue和break对if语句无关
  - **循环里面有switch，break会与内层反应，不会影响外部循环**
    - 1个break只能跳出1层

### 10.2 do while

### 11.1 控制台其他

- **清空控制台**
  - Console.Clear( );
- **设置控制台大小**
  - 先设置窗口大小，再设置缓冲区大小

  - 窗口大小不能大于控制台最大尺寸
  - **代码**
    - 窗口大小

      示例代码如下：

      ```csharp
      Console.SetWindowSize( 宽，高 );
      ```

    - **缓冲区大小（可打印内容区域大小）**
      - Console.SetBufferSize( 宽，高 )
  - **得到缓冲区边界大小**
    - x=BufferHeight
    - x=BufferWeight
- **设置光标位置**
  - 控制台左上角为（0， 0 ），右侧为x轴正向，下侧为y轴正向
  - 视觉上 y=2x
  - 注意边界
  - **语法**
    - **Console.SetCursorPostion(宽 ,高 )；**
      - 决定光标之后位置
- **设置颜色**
  - Console.ForegroundColor =ConsoleColor.颜色;
    - 颜色用英语
  - **背景颜色**
    - Console.BackgroundColor = ConsoleColor.颜色；

- **光标显隐**
  - **Console.CursorVisible =false ;**

- **关闭控制台**
