快速幂把指数拆成二进制。n 为奇数时先乘一个 x，然后底数平方、指数减半；n 为偶数时只做平方和减半。负指数先把底数取倒数，再把指数变正。ans 一开始传 1。

<!-- more -->

```cpp
#define ll long long
double pow(double x, ll n, double ans)
{
    if (n == 0)
    {
        return ans;
    }
    else if (n > 0)
    {
        if (n % 2 == 1)
        {
            ans *= x;
            return pow(x * x, (n - 1) / 2, ans);
        }
        else
        {
            return pow(x * x, n / 2, ans);
        }
    }
    else
    {
        x = 1 / x;
        return pow(x, -n, ans);
    }
}
```

计算 x^n、模意义下的幂、矩阵快速幂。每次把指数减半，时间复杂度 O(log n)，递归栈 O(log n)。
