快速幂把指数拆成二进制。n 为奇数时先乘一个 x，然后底数平方、指数减半；n 为偶数时只做平方和减半。负指数先把底数取倒数，再把指数变正。结果初始为 1。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

// 计算 x^n，支持负指数
double qpow(double x, ll n)
{
    double res = 1;
    if (n < 0) // 负指数：先取倒数，再把指数变正
    {
        x = 1 / x;
        n = -n;
    }
    while (n > 0)
    {
        if (n & 1) res *= x; // 这一位是 1，乘进答案
        x *= x; // 底数平方
        n >>= 1; // 指数右移一位
    }
    return res;
}

void solve()
{
    double x;
    ll n;
    cin >> x >> n;
    cout << fixed << setprecision(10) << qpow(x, n) << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

计算 x^n（含负指数）；模意义下的幂见「除法取模与逆元」，矩阵快速幂把乘法换成矩阵乘法即可。每次把指数减半，时间复杂度 O(log n)，空间 O(1)。
