模意义下不能直接做除法。(a / b) mod p 在 p 为质数时可以改成 a * b^(p-2) mod p，这里用了费马小定理。mypow 是带模的快速幂，指数按二进制拆开，每一步都取模，避免溢出。前提是 p 为质数，且 b 不是 p 的倍数。

<!-- more -->

```cpp
#define ll long long
#define mod (ll)998244353

ll mypow(ll x, ll n, ll ans)
{
    if (n == 0)
    {
        return ans;
    }
    else if (n > 0)
    {
        if (n % 2 == 1)
        {
            ans = (ans * x) % mod;
            return mypow((x * x) % mod, (n - 1) / 2, ans);
        }
        else
        {
            return mypow((x * x) % mod, n / 2, ans);
        }
    }
}
// 对于除法取余 (a / b) % mod 一般可以看成 a * pow(b, mod - 2) % mod;
// 在这个函数中，ans 初始传 1
```

计算组合数、概率期望、分数取模。快速幂 O(log p)，递归栈 O(log p)。
