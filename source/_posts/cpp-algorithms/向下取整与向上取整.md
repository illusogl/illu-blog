C++ 的整数除法向零取整，遇到负数就和数学上的向下取整不一致。修正方法是看余数是否为零，以及 a 和 b 是否异号：向下取整在余数不为零且异号时减一，向上取整在余数不为零且同号时加一。

<!-- more -->

```cpp
#define ll long long
//适应负数的向下向上取整
//向下取整
ll floor_div(ll a, ll b) {
    return a / b - (a % b && (a ^ b) < 0);
}

//向上取整
ll ceil_div(ll a, ll b) {
    return a / b + (a % b != 0 && (a ^ b) >= 0);
}
```

处理负数范围的除法、二分取中点、数论分块。只做几次整数运算，时间复杂度 O(1)。
