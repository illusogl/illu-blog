单调栈用来找每个元素左边或右边第一个比它大（或小）的位置。以左边第一个更大值为例：维护一个从栈底到栈顶递减的下标栈，新元素进来时，把栈顶不够大的都弹掉，剩下的栈顶就是答案。右边同理，从右往左扫一遍。

<!-- more -->

```cpp
void solve()
{
    vector<int> a = {2, 1, 2, 4, 3};
    int n = a.size();
    vector<int> nge(n, -1);   // next greater element 的下标

    stack<int> st;            // 存下标，栈内对应值单调递减

    for (int i = 0; i < n; i++)
    {
        // 当前元素比栈顶大，说明找到了栈顶的「下一个更大元素」
        while (!st.empty() && a[st.top()] < a[i])
        {
            nge[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }

    // 输出结果
    for (int i = 0; i < n; i++)
        cout << a[i] << " -> " << (nge[i] == -1 ? -1 : a[nge[i]]) << "\n";
}

```

求每个元素作为最值能扩展的区间、所有子数组最大值减最小值之和、柱状图最大矩形。每个元素最多进栈出栈一次，时间复杂度 O(n)，空间 O(n)。
