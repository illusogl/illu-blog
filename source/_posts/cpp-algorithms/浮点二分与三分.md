浮点二分用于单调判定，三分用于单峰函数求极值。固定迭代 100/200 次比写 eps 更稳，基本不会死循环。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

double f(double x)
{
    return -(x - 3) * (x - 3) + 5; // 单峰函数示例
}

bool check(double x)
{
    return x * x >= 2; // 示例：求 sqrt(2)
}

void solve()
{
    // 浮点二分：找第一个满足 check(x) 的位置
    double l = 0, r = 1e9;
    for (int it = 0; it < 100; it++)
    {
        double mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid;
    }
    cout << fixed << setprecision(9) << l << '\n';

    // 三分：求单峰函数最大值
    l = -1e9;
    r = 1e9;
    for (int it = 0; it < 200; it++)
    {
        double m1 = l + (r - l) / 3;
        double m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1;
        else r = m2;
    }
    cout << fixed << setprecision(9) << f((l + r) / 2) << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

浮点二分、三分求单峰极值。每次迭代把范围缩小，时间复杂度 O(迭代次数)，空间 O(1)。三分要求函数严格单峰；有平台或抖动时改用二分/枚举。
