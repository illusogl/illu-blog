Kruskal 把边按权值排序，用并查集判断是否成环，选够 n-1 条边就是最小生成树。负权边也可以直接做。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

struct DSU
{
    vector<int> p, sz;

    DSU(int n = 0)
    {
        p.resize(n + 1);
        sz.assign(n + 1, 1);
        iota(p.begin(), p.end(), 0);
    }

    int find(int x)
    {
        return p[x] == x ? x : p[x] = find(p[x]);
    }

    bool unite(int a, int b)
    {
        a = find(a);
        b = find(b);
        if (a == b) return false;
        if (sz[a] < sz[b]) swap(a, b);
        p[b] = a;
        sz[a] += sz[b];
        return true;
    }
};

struct Edge
{
    int u, v;
    ll w;
};

void solve()
{
    int n, m;
    cin >> n >> m;

    vector<Edge> edges(m);
    for (int i = 0; i < m; i++)
        cin >> edges[i].u >> edges[i].v >> edges[i].w;

    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.w < b.w; // 按边权从小到大
    });

    DSU dsu(n);
    ll ans = 0;
    int cnt = 0;
    for (const Edge& e : edges)
    {
        if (dsu.unite(e.u, e.v)) // 不成环就选这条边
        {
            ans += e.w;
            cnt++;
            if (cnt == n - 1) break;
        }
    }

    if (cnt != n - 1) cout << "not connected\n";
    else cout << ans << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

Kruskal 适合稀疏图，Prim 适合稠密图。排序 O(m log m)，并查集接近 O(1)，总时间复杂度 O(m log m)，空间 O(n+m)。
