对拍用一份保证正确但可能很慢的暴力，去检查正解的输出。gen 按 seed 生成小规模数据，sol 跑正解，bf 跑暴力，再比较两份输出；答案不唯一时改用 checker 判断合法性。seed 从命令行传入，出错后可以用同一个 seed 复现。下面给出最简版 gen.cpp 和 duipai.bat，比赛时只改生成数据的那一段。

<!-- more -->

```cpp
// 最简对拍数据生成器
// g++ gen.cpp -o gen.exe
// gen.exe 1 > in.txt
// sol.exe < in.txt > out1.txt
// bf.exe  < in.txt > out2.txt
// fc out1.txt out2.txt
#include <bits/stdc++.h>
using namespace std;

int main(int argc, char* argv[])
{
    mt19937 rng(atoi(argv[1])); // 同一个 seed 复现同一组数据

    // 只改这一段：按题意生成小规模数据
    int n = 10, m = 20;
    cout << n << ' ' << m << '\n';
    for (int i = 1; i <= n; i++)
        cout << rng() % m + 1 << " \n"[i == n];
}
```

配套的批处理文件，和 gen.cpp 放在同一目录：

```bat
@echo off
rem 最简对拍：编译三个程序，然后循环比较
g++ -O2 sol.cpp -o sol.exe
g++ -O2 bf.cpp -o bf.exe
g++ -O2 gen.cpp -o gen.exe

for /l %%i in (1,1,10000) do (
    gen.exe %%i > in.txt
    sol.exe < in.txt > out1.txt
    bf.exe < in.txt > out2.txt
    fc out1.txt out2.txt > nul
    if errorlevel 1 (
        echo WA seed=%%i
        type in.txt
        pause
        exit /b
    )
)
echo OK
pause
```

用来找正解的隐藏错误，尤其是边界和特殊构造。单组数据的耗时取决于 sol 和 bf；一般跑几千组小数据就能暴露大部分问题。
