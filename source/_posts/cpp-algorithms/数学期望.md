期望等于每个可能取值乘上它的概率再求和。下面的模板读入 n 组 (value, probability)，把 value * probability 累加即可。如果概率需要推导，先算出每个取值的概率，再套这个循环。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

void solve()
{
    int n;
    cin >> n;

    double ans = 0;
    for (int i = 0; i < n; i++)
    {
        double value, probability;
        cin >> value >> probability;
        ans += value * probability; // 期望 = Σ 取值 × 概率
    }

    // 概率题一般保留 9 位
    cout << fixed << setprecision(9) << ans << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

计算离散随机变量的期望，也常用于期望 DP 和概率题。每组数据 O(n)，空间 O(1)。
