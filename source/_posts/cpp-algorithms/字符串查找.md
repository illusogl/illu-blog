C++ 的 std::string 自带 find，找不到时返回 string::npos。判断子串是否存在，只要把 find 的结果和 npos 比一下。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

void solve()
{
    string s, p;
    cin >> s >> p;

    size_t pos = s.find(p); // 找不到时返回 string::npos
    if (pos == string::npos) cout << -1 << '\n'; // 没找到
    else cout << pos << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

判断子串是否存在、找第一次出现的位置。标准库的 find 最坏时间复杂度 O(nm)，额外空间 O(1)；数据大或需要多次匹配时用 KMP。
