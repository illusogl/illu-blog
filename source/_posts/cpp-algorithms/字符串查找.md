C++ 的 std::string 自带 find，找不到时返回 string::npos。判断子串是否存在，只要把 find 的结果和 npos 比一下。

<!-- more -->

```cpp
#include <bits/stdc++.h>
int main()
{
    //字符串找字串api，时间复杂度O（m * n）
    bool find = true;
    std::string father,son;
    if(father.find(son) == std::string::npos)
    {
        find = false;
    }
}
```

判断子串是否存在、找第一次出现的位置。标准库的 find 最坏时间复杂度 O(nm)，数据大或需要多次匹配时用 KMP。
