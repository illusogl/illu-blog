小根堆的堆顶始终是最小值。priority_queue 默认是大根堆，传 greater<int> 才变成小根堆。下面以最大重叠区间数为例：按左端点排序区间，用堆维护当前还没结束的右端点；左端点超过堆顶时，说明那段区间已经结束，弹掉。堆的大小就是同时重叠的区间数。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

// 最大重叠区间数
void solve()
{
    int n;
    cin >> n;

    vector<pair<int, int>> seg(n);
    for (auto& [l, r] : seg) cin >> l >> r;
    sort(seg.begin(), seg.end()); // 按左端点排序

    priority_queue<int, vector<int>, greater<int>> pq;
    int ans = 0;
    for (auto [l, r] : seg)
    {
        // 右端点小于当前左端点，说明区间已经结束
        while (!pq.empty() && pq.top() < l) pq.pop();
        pq.push(r); // 当前区间加入
        ans = max(ans, (int)pq.size()); // 堆大小就是同时重叠的区间数
    }

    cout << ans << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

维护当前最小值、合并区间、求最大重叠数、Dijkstra 的优先队列。每次插入或弹出 O(log n)，整体 O(n log n)，空间 O(n)。
