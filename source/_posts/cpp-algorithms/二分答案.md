二分答案把求最优值改成判断一个值行不行。先确定答案的范围，每次取中点 mid，用 check(mid) 判断；可行就记下答案并往更大的一边找，不可行就往更小的一边找。循环用左闭右闭区间，退出时 ans 就是最后一个可行的值。

<!-- more -->

```cpp
int left = 0, right = tLen;  // 能删 0 到全部
int ans = 0;

while (left <= right)
{
    int mid = (left + right) / 2;

    if (能匹配(mid))  // 删 mid 个后还能得到 p
    {
        ans = mid;       // 记录一下
        left = mid + 1;  // 试试能不能删更多
    }
    else
    {
        right = mid - 1; // 删太多了，少删点
    }
}
// 通用模板，左闭右闭
```

求最大值最小、最小值最大、第一个满足条件的位置。每次把区间减半，时间复杂度 O(log V) 次 check，空间取决于 check 函数。
