二分答案把求最优值改成判断一个值行不行。先确定答案的范围，每次取中点 mid，用 check(mid) 判断；可行就记下答案并往更大的一边找，不可行就往更小的一边找。循环用左闭右闭区间，退出时 ans 就是最后一个可行的值。下面以最大的 x 使 x*x <= n 为例。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

ll n;

bool check(ll x) // 按题目改：判断 x 是否可行
{
    return x * x <= n;
}

void solve()
{
    cin >> n;

    ll l = 0, r = 1e9, ans = 0;
    while (l <= r)
    {
        ll mid = l + (r - l) / 2; // 防 l+r 溢出
        if (check(mid)) // 可行，记录并尝试更大
        {
            ans = mid;
            l = mid + 1;
        }
        else
        {
            r = mid - 1; // 不可行，往小的一边找
        }
    }
    cout << ans << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) solve();
    return 0;
}
```

求最大值最小、最小值最大、第一个满足条件的位置。每次把区间减半，时间复杂度 O(log V) 次 check，空间取决于 check 函数。
