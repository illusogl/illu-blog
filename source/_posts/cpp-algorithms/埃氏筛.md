从 2 开始往后扫，遇到一个没被标记的数就认为它是素数，然后把它的倍数全部标记成合数。倍数从 i*i 开始，因为更小的倍数已经被更小的素因子筛过了。1 不是素数，初始化时要单独把 ans[1] 置为 false。

<!-- more -->

```cpp
#include <bits/stdc++.h>
using namespace std;
#define ll long long

vector<ll> get_p()
{
    vector<bool> ans(150000, true);
    vector<ll> ansV(10001);
    ans[0] = false;
    ans[1] = false;  // 1 不是素数
    for (ll i = 2; i < 150000; i++)
    {
        if (ans[i])
        {
            for (ll j = i * i; j < 150000; j += i)
            {
                ans[j] = false;
            }
        }
    }
    int index = 0;
    for (int i = 2; i < 150000; i++)
    {
        if (ans[i] && index < 10001)
        {
            ansV[index++] = i;
        }
    }
    return ansV;
}
```

预处理素数表、判断素数、分解质因数。时间复杂度 O(n log log n)，空间 O(n)。代码把上界写死成 150000，并取前 10001 个素数，换题时改这两个数即可。
