回溯是带撤销的 DFS。递归到某一层时，先判断是否满足终止条件，满足就记录答案并返回；否则枚举这一层能做的选择，做选择、递归、再撤销选择，回到进入这一层时的状态。

<!-- more -->

```cpp
// 回溯算法的通用 dfs
void backtracking(参数)
{
    if (终止条件)
    {
        存放结果;
        return;
    }
    for (选择 : 本层集合中的元素)
    {
        处理节点;
        backtracking(路径, 选择列表); // 递归
        撤销处理; // 回溯
    }
}
```

用来枚举排列、组合、子集，也用于棋盘、分割、路径这类搜索题。复杂度取决于搜索树的大小，通常是指数级；剪枝和可行性判断能减少很多分支。
