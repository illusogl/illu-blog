### 1.2 线性表

主要包括：

- n个相同数据类型的集合
- **特点**
  - 存在唯一 一个第一个节点
  - 存在唯一 一个最后一个节点
  - 除了第一个和最后一个，每个数据类型均有一个前驱一个后继
- **顺序表**
  - 用一组连续内存单元存各个元素，物理空间也是连续的
  - 存储结构

    示例代码如下：

    ```c
    #define MAX = 100;
    typedef int ElemType;	//数据类型定义为整形用Elem表示
    typedef struct{
    	ElemType data[MAX];
    	int length;
    }SeqList;
    ```

  - 初始化
    ```c
    void iniList（SeqList *L）
    {
    	L->length = 0;
    }
    ```

  - 添加
    ```c
    int append(SeqList *L ,ElemType e){
    if(L->Length>=Max){printf("满了");	return 0;}
    L->data[L->Length] = e;
    L->Length++;
    return 1;
    }
    ```

  - 遍历
    ```c
    void listElem(SeqList *L){
    for(int i = 0; i < L->Length; i++)
    ```

  - 插入


### 1.3 链表

- **任意存储单元的线性数据元素**
  - 节点包含数据域和指针域指针域信息叫指针
- 结构

  示例代码如下：

  ```c
  typedef  int ElemType;
  typedef struct node{
  	ElemType data;
  	struct node *next;
  }Node;//包含自己的元素和下一个节点的地址
  ```

- 初始化
  ```c
  Node * iniList()
  {
  	Node *head = (Node*)malloc(sizeof(Node));
  	head->data = 0;
  	head->next = NULL;
  	return head;
  }//初始化就是新建个头节点（用动态内存分配）
  ```

  - 应用 Node \*list = iniList( );
- **插入**
  - 头插法
    ```c
    Node*  insertHead(Node *L ,ElemType e)
    {
    	Node *p =(Node*)malloc(sizeof(Node));
    	p->data =e;
    	p->next =L->next;//先获取地址
    	L->next =p;//再给原先节点写地址
    	return p；
    }
    ```

    - 数据始终插到头节点后面一个
    - 得到的数据是反向的
  - **尾插法**
    - 要获取尾节点地址才能插
    ```c
    Node* listNode (Node* L){
    	Node *p = L->next;//L始终是头节点
    	while(p !=NULL){
    		p =p->next;
    	}
    	return p;

    Node*  insertTail(Node *tail ,ElemType e)
    {

    	p->data =e;
    	tail->next =p;
    	p->next = NULL;
    	return p;
    }
    ```

    - 先遍历再插入
    - 每次插入后返回尾节点，供下次直接插入
  - 插入指定位置
    ```c

    Node*p = L;
    ```

- 遍历

- **删除**
  - 找到删除节点的前置节点；<br>用指针计入要删除的节点；<br>改变p的后继指针实现删除；<br>删除节点空间
  ```c
  int delList(Node *L ,int pos)
  {
  	Node *p = L;
  	for(int i - 0 ; i< pos -1 ; i+=){p = p->next;}//p是要删除节点前驱
  	if(p->next ==NULL){return 0;}//要删除的位置没有数据
  	Node *q =p->next;//q指向要删除节点
  	p-next =q->next;//p指向q的后继
  	free(q);
  }
  ```

- **释放链表**
  - 指针p指向头节点后第一个节点<br>判断是否为空节点<br>如果不为空，用指针q记录p后继结点<br>释放p节点；<br>指针p指向指针q同一个位置，循环上面操作
  ```c
  void freeList(Node *L)
  {
  	Node *p = L->next;
  	Node *q;
  	while(p!=NULL){
  		q=p->next;
  		free(p);
  		q=p;
  	}
  	L->next =NULL;
  }
  ```

### 1.4 双指针

- **查找链表中倒数第k个元素——双指针**
  - 为了找到第k个值，可以使用快慢指针，让快指针先走k步，再让快慢指针一起走，当快指针指向空时，找到元素
- **查找两个链表共同后缀**
  - 获取两个链表A、B长度，让长的减短的得到m-n，让快指针再长链表先走m-n步，慢指针从短链表一起走，当他们指向地址相等时，得到后缀

### 1.5 空间换时间

- **删除链表中绝对值相同的节点**
  - 建一个数值对应的数组，当出现对应数字，让数组对应值加1，值大于1时，删除

### 1.6 链表反转

- 定义三个指针，第三个指针指向第二个指针地址，让第二个指针的地址指向第一个指针，让三个指针循环往前走

### 1.7 循环链表

- 用双指针，快指针走两步，慢指针走一步，不停循环，当两者指向用一个地址时，是循环链表
- **判断入口**
  - 当你指针在环里时，让指针走一圈，计算圈内有X个节点，<br>再声明两个快慢指针，让快指针先走X步，再让快慢指针同步走，相遇时快指针走完一圈，正好慢指针指向入口

### 1.8 双向链表

- 有两个指针域，一个前驱一个后继

### 2.1 栈

主要包括：

- 先进后出的线性表或链表

### 2.2 队列

- 先进先出线性表或链表，一端插入，一端删除
- **队列的线性结构**
  - 定义

