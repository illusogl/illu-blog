# 对拍模板使用说明

## 快速上手（3 步）

1. 把 `gen.cpp` 中标注的区域改成按题意生成**小规模**数据（n、值域压到个位数~几十）。
2. 把你的代码粘进 `sol.cpp`，手写一个保证正确的暴力放进 `bf.cpp`（随便超时）。
3. 在本目录运行（三选一）：

   ```
   duipai.bat            ← Windows 终端（CMD/PowerShell）直接输这个，或双击文件
   bash duipai.sh        ← 有 bash 的环境（Git Bash / 比赛机房 Linux）
   python checker.py     ← 答案不唯一时用这个代替（先改它的 check 函数）
   ```

挂了会打印 seed 和输入，输入同时存在 `in.txt`，用 `.\gen <seed> > in.txt`（CMD）可随时复现。

## 三个关键点

- **seed 当命令行参数**：挂了不改代码就能复现。
- **数据规模要小**：错误碰撞率才高；过了几千组再考虑加大规模。
- **答案不唯一（"输出任意一个/任意一组"）时 `diff` 会误报** → 用 `checker.py`，
  每道题只改它里面的 `check()` 函数（参考：Kay and Snowflake 重心题的写法）。

## 其他提醒

- 本地测**链形大数据**（深递归）会爆栈，编译加 `-Wl,--stack,268435456`；CF 上不用。
- gen 里可以加 `argv[2]` 当第二参数控制数据类型（随机/链/星形/全相同），分类型拍更有效。
