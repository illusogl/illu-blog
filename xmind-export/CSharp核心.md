# C#核心

## 面向对象

### 面向对象-封装

- 类和对象
  - class（对象的模板）
  - 类声明在namespace中，用帕斯卡命名法
  - 同一个语句块中类不能重名
  - 类语法
    ```csharp
    （访问修饰符public） class 类名
    {
    //特征——成员变量
    行为——成员方法
    保护特征——成员属性
    构造函数和析构函数
    索引器
    重载运算符
    静态成员
    }
    ```

  - 对象声明
    - 类的声明类似枚举，结构体，是一个自定义变量
    - 对象是类创建出来的（实例化对象）
    - 类是应用类型的，结构体是值类型的
  - 对象语法
    - 类名 变量名；<br>类名 变量名 = null；（null代表空）（改变指针变为哪里也不指）<br>类名 变量名 = new 类名（）；
    - 即使是来自一个类的对象，两者不共享数据
- 成员变量
  - 与结构体类似，可声明任意变量类型（区别是可以赋值）
  - 类里面 同名类型的成员变量 一定不能初始化
  - 访问修饰符
    - public 公用
    - private 私有 只能在类内部用
    - protected 保护 只要自己和自己子类才能用
  - default（变量类型） 得到变量的默认值
- 成员方法
  - 写在class里，规则与函数一致
  - 与结构体里函数相似，不写static
  - 成员方法要实例化才能使用
- 构造、析构、垃圾回收
  - 构造函数
    - 如果不写默认存在一个无参的构造函数
    - 构造函数类似结构体的构造函数
    - 类中允许自己声明无参构造函数<br>结构体不允许
    - 构造函数可以重载
  - 构造函数特殊写法
    - 通过this重用构造函数代码
    - 访问修饰符 构造函数名（参数列表）：this（参数1，参数2）
    - 先进入this的构造函数，在进入自身
  - 析构函数
    - 堆内存被回收，调用该参数
    - 需要手动管理内存的语言（c++），需要用析构进行内存回收
    - ~类名（）<br>{<br>}
  - 垃圾回收机制
    - 过程就是遍历堆（Heap）上的所有对象，判断他们是否被引用，垃圾会被回收
    - 有多种算法<br>引用计数，标记清除，标记整理，复制集合
    - 堆的内存只能用回收机制管理<br>栈（stack）上的内存系统自动管理
    - GC耗时，会卡顿，往往在loading时GC
    - GC.Collect( )；手动垃圾处理
    - 概念
      - C#中内存回收机制的大概原理<br>0代内存     1代内存     2代内存<br>代的概念：<br>代是垃圾回收机制使用的一种算法（分代算法）<br>新分配的对象都会被配置在第0代内存中<br>每次分配都可能会进行垃圾回收以释放内存(0代内存满时)<br>在一次内存回收过程开始时，垃圾回收器会认为堆中全是垃圾，会进行以下两步<br>1.标记对象 从根（静态字段、方法参数）开始检查引用对象，标记后为可达对象，未标记为不可达对象<br>不可达对象就认为是垃圾<br>2.搬迁对象压缩堆  （挂起执行托管代码线程） 释放未标记的对象 搬迁可达对象 修改引用地址<br>大对象总被认为是第二代内存  目的是减少性能损耗，提高性能<br>不会对大对象进行搬迁压缩  85000字节（83kb）以上的对象为大对象
    - 数组的扩容容易产生垃圾，所以每次扩容可以新建一个两倍大的数组搬家
- 成员属性
  - 保护变量，为成员属性获取和赋值加逻辑
  - 帕斯卡命名法
  - 语法

  - 使用

    - 默认不加，权限为属性声明时的权限
    - 加的修饰符要低于属性的权限public&gt;protected&gt;private
    - 不能两权限个都低于属性的权限
  - get 和 set 可以只有一个
  - 自动属性
    - 外部能得不能改，又没有特殊处理

- 索引器
  - 通过索引访问元素，类似数组

- 静态成员
  - 关键字 static<br>直接用类名点出来使用，不需要声明对象

    - 常用唯一的变量声明<br>方便别人获取对象的声明<br>常用的规则方法声明
  - const（常量）是特殊的静态
    - 区别：const必须实例化，static不用<br>const不能被修改，static不用<br>const必须写在修饰符后面，static不用
- 静态类和静态构造函数
  - 静态类
    - 只能有静态成员，不能被实例化
    - 将常用静态成员写这里，体现唯一性
  - 静态构造函数
    - 静态类和普通类都可以有
    - 只能调用一次，在第一次使用类的内容时调用
    - 不能有参数，不能有访问修饰符
    - 初始化静态成员
  - 单例模式
    - 创建一个唯一类的同时，让类不是静态类
    - 1、在类中创建一个类型为自己的静态变量<br>2、声明一个成员属性来让其只可访问，不可set<br>3、将构造函数改成私有
- 拓展方法
  - 为非静态的变量类型添加方法（int，类）

    - 写在静态类

- 运算符重载
  - operator
  - 特点
    - 一个公用的静态方法

      - &gt;, &lt;,==,!=,&lt;=,&gt;=<br>他们要两两配对的写，写了&gt;就要写&lt;
    - 不可重载
      - &amp;&amp;，||<br>索引符\[ \]<br>强转符( )<br>点.	三目运算符？ ：	赋值符号=

  - 内部类

### 面向对象-继承

- 继承的基本规则
  - 基本概念
    - 一个类A继承一个类B
    - 类A会继承类B所有特征和行为
    - 特点
      - 子类只有一个父类-单根性
      - 子类可以间接继承父类的父类-传递性
  - 语法
    ```csharp
    class 类名 ：被继承的类名
    {

    }
    ```

  - 访问修饰符
    - protected - 保护 只有内部和子类使用<br>internal - 内部的 只有在同一个程序集文件中，内部类型或成员才能访问
  - 子类和父类成员可以重名 但是不要用
- 里氏替换原则
  - 面向对象7大原则中重要原则
  - 概念：任何父类出现的地方，子类都可替换
  - 语法表现
    - 父类容器可装子类对象，子类对象包含父类所有内容
    ```csharp
    Gameject player = new Player( );
    GameObject是父类
    定义了一个父类变量，但其是子类变量
    ```

    - 后续可用as转换为子类变量
  - is 和 as
    - is 判断一个对象是否是指定类对象<br>返回bool值 是为真
      - 例：if （player is Player）player是变量Player是类
    - as 将一个对象转换为指定类对象<br>返回 指定类型对象
      - 例：Player p = player as Player； player是变量 Player是类
      - 成功返回对象 ，失败返回null
- 继承中构造函数
  - 概念
    - 特点先执行父类构造函数，在执行子类构造函数
    - 父类的无参构造很重要
    - 子类可以通过base关键字 代表父类 调用父类构造
  - 当你声明子类，调用子类构造函数时，程序会先调用父类的构造函数
  - 父类的无参构造被顶掉时，无法实例化子类
    - 因为声明子类会调用父类构造
  - 通过base 调用指定父类的有参构造
    ```csharp
    构造声明时 
    public Son（int i）：base（i）{  }
    //其父类构造函数为有int i 的有参构造
    ```

  ```csharp
  base 后面括号可以指定为常量，前面可以为无参
  public Son（ ）：base（10）{  }
  ```

- 万物之父和装箱拆箱
  - 万物之父
    - object
    - object是所有类型的基类，一个类（引用类型）
    - 使用
      - 引用类型
        ```csharp
        object o =new Son（）；
        if（o is son）{ (s as son).Speak( ); }
        用object装Father类 的子类Son类
        ```

      - 值类型

        ```csharp
        float f =(float)o;
        用括号强转
        ```

      - string类型
        - string str =str.Tostring( );
        - as
  - 装箱拆箱
    - 用object存储值类型是装箱<br>用object转为值类型是拆箱
    - 把值类型放到堆中
    - 优缺点
      - 不确定类型是方便参数存储但存在内存迁移增加性能消耗

  - sealed密封关键字修饰的类<br>让类无法继承
  - sealed class Father

### 面向对象-多态

- vob
  - 多态概念
    - 同一个父类的子类<br>在执行相同方法时有不同表现
    - 让同一个对象有唯一行为特征
  - 让同一对象有唯一特征
  - vob<br>virtual（虚函数）<br>override（重写）<br>base（父类）
  - 父类写函数加virtual<br>子类写override补全，用以重写函数
  - base是来执行父类的代码
  - 作用
    - 加了vob后用里氏替换原则<br>当父类转子类时，执行子类方法
- 抽象类和抽象方法
  - 抽象类
    - abstract
    - 特点
      - 不能被实例化
      - 可以包含抽象方法
      - 继承抽象类必须重写抽象方法
      - 抽象类中封装的所有知识点都能实现
    - 虽然不能实例化，但可以用父类装子类
  - 抽象函数
    - 特点
      - 只能在抽象类中声明
      - 没有方法体
      - 不能是私有的
      - 继承后必须实现，用override重写
    - abstract关键字
    - 类似虚方法（virtual）
    - 虚方法和抽象方法都可以无限重写
- 接口
  - 行为的抽象规范 关键字 interface
  - 声明规范
    - 不包含成员变量
    - 成员不能被实现
    - 成员可以不写访问修饰符，不能是私有
    - 接口不能继承类，但能继承接口
    - 只有方法、属性、索引器、事件
  - 使用规范
    - 类可以继承接口
    - 类继承接口和必须实现所有成员
  - 特点
    - 和类相似
    - 用来继承的
  - 声明
    ```csharp
    interface 接口名
    {
    }
    接口是抽象行为的”基类“
    命名规范：帕斯卡命名法，前面加个I
    ```

    ```csharp
    interface IFly
    {
    int this[int index]{get;	set;}
    int Name{get;	set;}
    }
    ```

    - 如果接口访问修饰符写保护的<br>后面要显示实现接口
  - 使用
    ```csharp
    class Son：Father，interface1，interface2
    {
    }（接口的东西都要实现，点击灯泡自动补全）
    ```

    - 类可以继承1个类，n个接口
    - 继承接口后 必须实现其中内容 并且必须是public
    - 实现的接口函数，可以加virtual ，再在子类中重写
    - Iinterface I =new Father（）；<br>接口不能实例化，接口遵循里氏替换原则
  - 接口继承接口
    - 接口继承接口时，不需要实现<br>等类继承接口时 类中实现内容
  - 显示实现接口
    - 当一个类继承两个接口<br>但接口中有同名方法时使用
    - 这样会让同名方法无法在类中使用，要as转换来使用
- 密封方法
  - sealed修饰的类，无法继承
  - 用sealed 修饰的重写函数<br>让它不能被再次重写（override）

### Stringbuilder

- String改变容易造成垃圾过多
- Stringbuilder可以修改字符串不创建新对象
- 使用时需要引用命名空间using System.Text；
- 与string不同，其可以改变原字符串，不用赋值
- 容量
  - StringBuilder会有默认容量16
  - 每次超出容量都会扩容，扩容变为2倍
- 初始化
  - StringBuilder str = new StringBuilder（“1235”）；
  - 重载StringBuilder str = new StringBuilder（“1235”，100/\*最大容量\*/）；

### 结构体和类的区别

- 结构体是值，类是引用
- 结构体有封装的特性，但没有继承和多态的特性
- 区别
  - 结构体不能用protected
  - 结构体本身不能是静态的
  - 结构体不能在自己内部声明和自己一样的变量
  - 结构体要在构造函数初始化所有成员变量
  - 结构体不能声明无参构造函数
  - 结构体不能声明析构函数
- 结构体特别之处
  - 结构体和类一样可以继承接口

### 抽象类和接口的区别

- 区别
  - 抽象类可以有构造函数，接口不能
  - 抽象类只能被单一继承；接口可以被多个继承
  - 抽象类可以有成员变量；接口不能
  - 抽象类可以有虚方法，抽象方法，静态方法；接口只有抽象方法
  - 抽象类可以有访问修饰符，接口默认public
- 表达对象用抽象类（动物），表示行为用接口（飞）

### 面向对象7大原则

- 为了高内聚低耦合
  - 减少类内部对其他类调用
  - 减少模块间交互复杂度
- 单一责任原则
  - 类被修改概率大，不应该把多个功能放一个类中
- 开闭原则
  - 对扩展开放，对修改关闭
  - 例如继承，只加不改
- 里氏替换原则
  - 任何父类出现，子类可以替代
- 依赖倒转原则
  - 要依赖抽象，不要依赖具体实现
- 迪米特原则
  - 一个对象，应该对其他对象尽可能少的了解
  - 降低耦合性
- 五大原则之外
  - 接口分离原则
    - 一个接口应该只有一个功能
    - 让别人通过接口选择接口
  - 合成复用组成
    - 尽量使用对象组合，减少继承
